# Version 4 feature acceptance — completion pass 2026-10-16

Local implementation and live acceptance are separate. The release report records actual deployed checks.

| Feature | Implemented and automated checks | Remaining external acceptance |
|---|---|---|
| Personal ranking | Owner-scoped profiles, PDF/DOCX/TXT extraction, approved evidence, explanations, constraints, saved actions | Candidate-specific ranked live-job review; desktop/mobile interaction |
| Job Radar | Saved official sources, body/time caps, trusted ATS feeds, max-three detail verification, snapshots/diffs, opt-in daily/weekly cursor/lease, retry | Source availability varies; unattended dispatcher needs configured external scheduler; 10 ranked live roles |
| Recruitment contacts | Saved-source public collection, classification, explicit-email-only, DNC, corrections, provenance | Real public sources may expose no recruiter; no guessed addresses |
| Application CRM | Stages/events, follow-ups, Kanban/table, exports, internal agent create/update | Deployed browser interaction |
| Application packs | Evidence-constrained editable drafts, low-reasoning optional model path, real PDF/DOCX/HTML exports | User approval of factual CV content; live model acceptance |
| Sector pitches | Four distinct playbooks, evidence references, editable revisions | Current company facts depend on available saved sources |
| Hiring signals | Official-source collection, dated candidates, quality, expiry, corrections/suppression | News coverage depends on saved source; no invented hiring evidence |
| Dublin/permit reality | Dated rule registry, uncertainty labels, official-source availability/hash refresh | Source retrieval does not approve legal interpretation; role/person eligibility stays reviewable |
| Interviews | Dublin scheduling, UTC storage, source/STAR preparation, practice, outcome, follow-up approval, real document exports | Calendar remains manual; deployed browser interaction |
| Command Centre/agent | Real KPIs, distinct-job counts, actions, validated internal tools, step claims/cancel/resume/retry, actual export links, estimated cost labels | Actual provider costs not measured; no unapproved outbound actions |

Additional workflows: versioned saved searches over local records; explicit in-app digest consent, IANA timezone and DST-aware quiet hours. No automatic paid search or outbound digest sender is introduced.

Strict full acceptance is not claimed without browser, live provider and controlled Gmail evidence. No recruiter is contacted during release testing.
