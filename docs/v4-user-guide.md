# Dublin Tech Compass Version 4 user guide

1. Open **Candidate Profile & CVs** and create a strategy. Add target families, skills, Dublin/remote constraints and approved evidence. Upload a master CV version; the original is kept private and upload does not start research.
2. Use the company workspace **Sheet view** to inspect and edit imported Excel fields, or **Detailed view** to inspect one company. The four sector links—Ecommerce, Startups, Tech Permits and Fintech—remain in the sidebar.
3. Enrichment is secondary and explicit: select existing companies and press **Research selected**, or choose a sector and press **Research all in sector**. Imported values remain attached; research fills gaps. Routine enrichment uses GPT-5.6 Luna low reasoning. The assistant uses medium reasoning. Tavily is reserved for bespoke search mode.
4. Open **Job Radar**, choose a company and paste its official careers URL. Press **Refresh official source**. Saved roles show source status and checked date. Blocked/empty sources are kept as source states.
5. Open **Opportunities**, choose a profile and review the heuristic score, confidence, matched evidence, gaps and unknowns. Star or dismiss an opportunity; use the source link for the employer’s current posting.
6. Open **Permit reality** to evaluate a role against the effective rule version, Dublin evidence and published salary. Treat potential/cannot-determine labels as review prompts, not legal conclusions.
7. Open **Applications** to create a target from a company/manual posting link. Move it through canonical stages with the stage selector. Use **Prepare application pack** to create an editable, evidence-constrained draft. If OpenAI is available the pack requests low reasoning; if not, a deterministic safe draft is retained. The master CV is never overwritten.
8. Open **Sector Pitches**, select E-commerce, Startups, Fintech or Work Permit Companies, select a profile, supply current company facts from sources, edit the result and save a new version.
9. Open **Recruitment Contacts** to add only a public contact with its source URL. Generic company inboxes remain separate from named recruiter contacts. Mark a contact do-not-contact when needed.
10. Open **Outreach & Email** to create one draft for one public contact. Review it, approve the individual send, then send only when you intend to call Gmail. The app never guesses an email address and never treats an attempt as sent without provider confirmation.
11. Open **Interviews** to schedule an application-linked interview in Europe/Dublin time. Generate a source-labeled pack from approved evidence, edit practice answers, record the outcome and follow-up, then use **Export printable pack**. Follow-up approval records the draft; Gmail sending remains separate.
12. Use **Today** for saved counts, open actions and the stage funnel. Use **AI Job Hunt Agent** for owner-scoped read/draft tasks. The run controls allow safe execution, cancel, resume and retry from a saved checkpoint; send/apply/schedule tools are stopped at an approval boundary.

On mobile, use the menu button, choose a sidebar destination, and use Escape or the close button to dismiss the drawer. Pages stay inside the authenticated app shell beside the sidebar. Browser QA against the deployed Site remains pending until an authenticated staging session is available.

## V4 quick start

1. Open **Candidate Profile & CVs**, save a strategy, upload your CV, and explicitly approve truthful achievement evidence.
2. Use any of the four sector Sheet/Detailed views; imported source fields remain available.
3. Open **Job Radar**, select a saved company and its official career source, then refresh. Unverified links and blocked sources stay labeled. Choose only selected companies for optional recurring scope; Run due now uses that scope.
4. Open **Opportunities**, rank with your candidate profile, inspect evidence/gaps, and prepare an application draft. Review/edit before exporting Word/PDF.
5. Track status and next action in **Applications**. Use **Outreach & Email** to connect Gmail, review a sourced contact and approve each send.
6. Save your preferred local queries under **Saved searches**. The in-app digest requires opt-in and respects your timezone/quiet hours; it does not send emails.
7. Save an interview with a Dublin date/time under **Interviews**, prepare and edit the pack, then export PDF/Word and record the outcome.
8. Use **AI Job Hunt Agent** for bounded saved-data research/drafts/internal tracking. Estimated budgets are shown; external sends/submissions still require their separate approval.
